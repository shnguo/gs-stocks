# 20万元A股研究：优势方向与验证方案

编制日期：2026-10-12，按用户洛杉矶日期记录。交易日、披露与决策时点一律使用上海时区。

用户已提供资金规模20万元、佣金万分之五、每笔最低5元，并明确要求全自动、无需人工参与。券商名称及佣金是否含规费尚未核实；10%回撤、20个交易日持有仍为研究提案，并非已经确认的账户风险偏好。本文没有收益承诺，也没有把现有模型晋级为盈利策略。

## 建议与依据

优先验证一个窄方向：公开的新增盈利改善信息，在首个完整交易日收盘后得到价格与成交量确认，随后20个交易日是否存在成本后的延续收益。

第一版只研究具有明确数值的业绩预告，避免把预约披露日当成利好。一般财报、回购、政策、主题新闻留给后续独立实验。现有五日模型先作为对照；只有事件方向自身通过检验，才研究模型能否增加价值。

这里的“最值得验证”来自经济机制、现有工程基础和20万元资金条件，不能解释为已测出它比其他策略收益更高。当前没有一个方向已经得到稳定净收益证明。付费前提应理解为可复查、成本后、跨时期仍有经济价值的优势；每月都赚钱不是可承诺的验收目标。

### 为什么事件信息值得优先补

系统已有事件版本库、实际可用时间、正式MA5、成交量/过热门槛、不可变决策与成熟结果复盘，能复用验证基础。

但现有交易所和巨潮采集器主要读取定期报告预约；财务传导、预期差、实际财务值等字段为空。它提供“何时披露”的信息，尚未提供“披露了什么、比此前已知信息好多少”。常规本地数据及artifacts顶层也未发现可直接使用的事件数据库；这只是有界位置核查，不代表远程归档或其他路径没有该文件。

新增信息应来自公告原文中的数值、报告期和修订记录。盈利同比增长不等于超出市场预期；没有当时可见的分析师预测或可复现的时间序列预期，就只称“新增盈利改善信息”。模型能帮助提取原文与解释，但不能凭文本语气编出预期差或财务数字。

历史研究为公告后价格反应延迟提供假设依据：[中央财经大学学报的A股研究](https://xbbjb.cufe.edu.cn/EN/Y2021/V0/I6/27)、[中国股票市场公告后收益研究](https://www.sciencedirect.com/science/article/pii/S1042443111000205)。其样本时期、持有窗口与多空设计不等于本方案，不能用论文收益替代当前A股现金多头检验。

## 第一版实验：只固定一个主要假设

假设：明确的盈利改善公告加上事后价量确认，相比同日、同板块/行业、相近历史价格表现与风险的无相同事件股票，产生额外的20日成本后收益。

基本观察单位为公司×报告期×新增信息版本。一次预告的同样数字在快报和正式报告中重复出现，不能再次记为新利好；更正或追加数字另存版本，第一版每家公司每报告期最多入场一次。预告、实际报告、分红、公司行动与退市结算各自保留原始来源和真实可见时点。

### 股票与事件范围

- 首版限定历史身份明确的沪深主板普通A股，包含历史退市成员；这不是全A股结论。创业板、科创板和北交所须确认用户实际交易权限及对应规则后另登记。
- 已上市至少120个交易日，前20日平均成交额至少3000万元。只使用当时已知的正常风险状态；ST、*ST和未知不允许新买入。
- 只接受第一次公开且数值可核验的盈利改善业绩预告：上一年同报告期归母净利润为正，公告披露的本期同比增长下限至少30%。直接采用原文同口径字段；缺失、口径冲突和前期亏损不硬算同比，记录剔除。
- 30%是固定研究起点，并非验证过的最优值。本轮不遍历10%、20%、50%等阈值。扭亏、扣非利润、现金流、分析师预期差作为后续独立方向，不混入首版主假设。
- 共同买入门槛为已完成复权收盘价不低于正式MA5。事件后确认额外要求MA5上升、当日成交量不低于此前20日均量，以及现有雷达的过热判定为否。
- E0与E1均在信息可用日之后第一个完整交易日收盘评价。即使公告早于当天开盘，也保守等待其后一个完整交易日，避免发布时间只有日期的记录获得不应有的速度优势。
- 第一完整收盘没有通过E1门槛，就跳过该事件；不事后选择最有利的确认日。真实历史发布时间不能证明时，从本地首次观测起计；不能用现在抓取的旧公告反推当年可见。

### 四组固定对照

| 组 | 选择依据 | 用途 |
| --- | --- | --- |
| P | 单纯过去20日涨幅排序，同样价量与可成交门槛 | 判断是否只是动量、风险或市场上涨 |
| M | 现有冻结版本的五日模型排名，同样价量与可成交门槛 | 判断复杂模型是否优于简单规则；这里只用排名，不冒称20日预测 |
| E0 | 新增盈利改善事件，仅共同MA5门槛 | 分解价量确认的增量；与E1共享事件信息评价日 |
| E1 | 新增盈利改善事件＋完整收盘价量确认 | 唯一主要候选 |

各组均以同一20万元现金账户、同一持有窗口和相同成交约束独立记账。E0和E1先按首次公布时间、同比增长下限、证券ID的固定顺序排序，不先引入模型、不使用主观目标价或70/20/10综合分。

主比较另生成P_matched_exposure：在E1每个入场日，按相同初始资金权重和20日窗口，提前冻结不具有同样事件的价格对照。严格匹配主板组、当时行业，并对20日动量、波动率、成交额和流通市值分位各用0.10卡钳。对照“没有事件”也必须有完整公告覆盖证明，不能把漏采当成没有公告。

匹配阶段不读未来收益；匹配权重覆盖至少90%，否则主要增量结论不合格。未匹配事件仍保留在完整账户结果，另报覆盖与匹配平衡。匹配是观察性增量证据，不能宣称随机因果实验。P独立账户、M、E0、沪深300含分红基准同时披露，但不根据它们的事后表现重新选择主要对照。

## 20万元账户与成交规范

- 六个持仓槽位，每个新仓最多初始资本15%，即3万元；总初始投入最多18万元，其余现金保留。行业投入上限30%。持仓涨跌自然漂移，不为恢复等权每天交易。
- 不要求凑齐六只。无事件、缺资料、没有匹配或无法成交均显式记录。无法成交的已选股票当日不以排名更低股票补位。
- 当天完成收盘信息后产生信号，下一交易日09:00前冻结，09:15为硬截止；迟发仅记回顾。下一交易日开盘是明确标注的条件成交情景，需要停牌、涨跌停、量额和当期交易规则证据。
- 开盘向上跳空超过信号日ATR14的一倍，取消当日入场；没有成交的订单当日到期，不持续追价。成交参与率最多此前20日平均成交额的0.5%。
- 主要持有期为20个交易日，次日开盘入场、20个持有交易日后的开盘退出；5日只作预登记的次要观察。不得事后选择最高价卖出、最低价买入或最优持有日。
- ST或身份风险触发退出请求；停牌、跌停和结算限制导致无法卖出时继续持有、估值、计提损益并记录陈旧估值。退市和无法核实的终值不填零、不从赢家均值里删除，资格验收必须补齐结算证据或提供保守边界。
- 原始价格用于撮合，复权序列用于技术计算及比较；公司行动权益、现金分红、应收款和现金仓位进入账本。日线只能给条件成交情景；延迟一天成交压力检验仍须通过，后续小额真实成交才可校验执行假设。
- 暂提账户回撤10%即停止新开仓并审查，已持有及无法卖出的仓位继续记账。该值尚待用户风险偏好补充，不能保证最大损失不超过2万元。

费用采用用户确认的佣金万分之五和历史生效的税费/过户费。每笔最低5元已获用户确认；佣金是否含规费仍需核实，避免重复收费或漏算。滑点每边5/10/20基点，主情景每边10基点；压力情景加倍佣金和滑点，法定税费仍按当时规则。最低佣金必须逐笔算，不用统一减0.25%替代。

历史税费不能把今天规则回填所有年份；[税务总局2023年减半征收公告](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5211343/content.html)说明规则具有生效日期。资料、软件订阅和研究服务费用另列，再从用户经济收益中扣除。

## 时间切分、统计与验收

历史阶段：在来源条件允许时，用三年训练、一年验证、下一季度评价的滚动结构检查经济机制、成本敏感性和失败时期。按实际标签结束日期清除跨分区重叠，至少20交易日隔离。已被前期研究查看过的2024—2025日期以及未知预训练重叠的模型历史，全部视为开发证据。只有经实验登记和模型预训练范围审计确认从未接触过的日期才能称保留集；没有这样的日期，就依靠新前瞻记录。

前瞻从协议、资料与代码注册后首个能够及时冻结的交易日开始。每天所有四组都保存，包括没有信号的现金日。第120个交易日只做运营、覆盖和风险审查，不做显著性晋级；第504个交易日进行唯一正式统计判定，第252日不提前检验。至少100个已完成主要持有窗口的独立公司×报告期事件和60个有效入场日，否则结论为证据不足。观察504日也不保证必然取得显著结果；样本不足判未建立优势，不自动延期。末尾未满20日的持仓保留在账户估值，不冒充成熟单笔结果；数据中断时保留原持仓和未知/陈旧估值，不把停机自动当成持有现金。

主要指标为E1与P_matched_exposure的每日账户净收益差，年化按252倍日均差计算；两者账户收益、CAGR、风险、现金暴露另行披露。采用配对日期区块自助法，区块20个交易日、重复10000次、固定种子20261012。不能把1000个重叠股票配对当作1000次独立试验。仅一个主要统计检验；其他组和5日窗口为描述性，不事后择优晋级。

以下是建议的研究门槛，不是已实现的成绩或市场收益预期：

| 关口 | 必须同时满足 |
| --- | --- |
| 经济性 | E1账户成本后总收益为正；对匹配价格对照的年化净增益至少5个百分点 |
| 统计支持 | 唯一正式评价时，主要收益差的95%区块区间下限大于0 |
| 风险 | 账户最大回撤不超过研究提案10%；无法卖出和未知终值不被删除 |
| 摩擦 | 加倍佣金与滑点后账户收益、对主要对照的增益仍为正；延迟一天入场时两者也须为正 |
| 稳定性 | 八个连续63交易日区间至少六个净增益为正（注册前待固定约定）；剔除最盈利五个事件交易后增益仍为正 |
| 可信度 | 纳入决策100%及时且有输入/代码版本；匹配权重覆盖至少90%；正式交易证据通过 |

5个百分点的经济门槛锚定20万元约1万元/年的增量价值，便于判断后续资料和服务成本是否值得；它不是预测。即使达到此门槛，付费后用户是否仍受益也要单独计算。风险门槛与商业门槛在正式前瞻登记前可根据用户补充调整，登记后不能按结果放宽。

## 执行顺序与淘汰规则

1. 前3—5个工作日：恢复行情、冻结记录和资料审计；核实佣金包含项目及风险偏好，完成协议注册准备。此阶段没有收益结论。
2. 随后约10个工作日：完成一个业绩预告类型的提取、固定100份原文自动校验、历史资料关口与20万元账本。若关键来源不可得，交付缺口清单，历史净收益验收保持阻断。
3. 随后约5个工作日：完成四组滚动开发比较与执行压力检验。固定规则若成本后为负，终止这个版本；任何新阈值必须登记新版本，不能在同评价集上搜索到正收益。
4. 满足资料和工程条件后开始冻结的前瞻影子账本，累计120日运营审查、504日唯一正式判定。以上工程工期是估计，数据缺口会影响进度；现在没有启动未来定时任务。
5. 只有E1先通过，才开下一项独立实验：同样事件队列下，E1按事件规则排序对照E1按现有模型排序。训练目标改为下一可交易开盘至固定退出的成本后收益/风险；五日与二十日目标分别登记，不沿用最低至最高价标签来证明净利润。

若第504个观察交易日E1仍未通过，记录“该版本未建立优势”，保留所有现金日、失败事件和成本，不用改名、删差月份或挑单个种子重新包装。模型误差改善可以继续用于研究解释，但不能因此出售稳定收益结论。
