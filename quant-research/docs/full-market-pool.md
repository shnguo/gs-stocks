## 覆盖规则

默认研究配置只接受 all_a_shares。全市场构建器不接收自选或行情清单作为成员输入；它核验市场来源成员数、重复身份以及三个市场的覆盖，保留停牌证券。

Python 在训练前读取固定目录并重验哈希，逐证券比较研究日期内的上市区间、交易日历和日线。缺证券、缺日历、缺价格和日期不完整分别进入台账。成员集合不因缺数据而缩小；历史身份未验证也不会被伪装为已通过。

已有八股快照相对 v2 研究范围缺少 5,804 条历史证券记录，默认 CLI 在创建训练输出前拒绝该快照。小样本只能显式使用 --test-fixture，并标记为工程测试；正式数据条件仍单独检查。

47 项 Python 测试、158 项 Rust 目标包测试、Ruff、Clippy 与格式检查通过。回归覆盖完整成员、价格缺口、来源数量和重复代码、Tushare 新主表、未知交易状态，以及失败续采与接口暂停。
