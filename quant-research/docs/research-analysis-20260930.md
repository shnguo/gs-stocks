# 以分析质量为主线的研究页

按用户最新方向，默认工作流暂不运行成交模拟，优先解释冻结候选并对照后续行情。已有交易模块、正式证据与不可变报告保留；需要时仍可明确启用。

## 已实现

- 切换信号日、收益主榜、上涨初期榜及已经发布的事件榜，查看冻结前20名。
- 候选解释包括原排名、模型参考收益、模型分歧、信号日之前的5日/20日涨跌、20日均线距离、历史波动和成交额，以及实际资料限制。
- 每只股票展示五个预测交易日的参考收盘、模型分位带、实测收盘和状态，并按信号日收盘归一为100绘图。缺失实测记录不会连线。
- 分别计算开盘、最高、最低、收盘价格误差、偏差与分位带命中；另提供逐预测日收盘质量，以及板块、行业、历史波动率分组。
- 同一批可对照记录包含朴素基线：使用信号日收盘预测后续价格。模型误差必须结合基线判断，不能仅看方向比例或榜单参考收益。
- 跨信号日按记录数量加权，不平均每日百分比。迟发回顾、有效前瞻和合成验证保持分开。
- 页面明确显示实际行情日期、上一完整交易日和后续缺口；辅助来源收起展示实际获取时间。

## 口径

每条样本是一份信号、一只冻结候选、一个预测交易日和一个价格字段。平均价格误差为预测价/实测价-1的平均绝对值；预测偏差保留符号。涨跌方向指预测和实测价格分别相对信号日收盘的方向。

原榜单参考收益采用低价至未来高价情景，不能作为收盘价格预测的准确度。每日参考价是各模型中位预测的均值；分位带是各模型10%/90%分位值的均值，不是经过校准的80%概率区间。窗口重叠不是独立样本，榜单组成不同也不能作为筛选方法改善的因果证据。

对照使用完整正值量价，并要求来源复权因子和价格序列与信号日一致。已知停牌、零成交量、缺行情和资料边界变化分别保留状态。交易状态字段缺失不会伪装为停牌，候选旁保留来源限制。来源因子连续不等于公司行动条款已验证，分析对照不会升级正式交易资格。

历史趋势只读冻结的信号日之前行情，要求连续21个交易日及相同价格序列。后采集的行业、风险资料不会回填旧候选的判断。

## 默认刷新

在 quant-research 目录执行：

    PYTHONPATH=src:scripts .venv/bin/python scripts/review_daily_research.py \
      --store artifacts/daily-token-live-v2 \
      --output ../stock-indicator-dashboard/public/research/latest.json

这条命令复用已有预测和冻结记录，追加带哈希的 analysis-reviews，不训练、不推理、不采集网络数据、不生成成交快照或运行交易模拟。每日手动入口同样默认导出分析摘要；显式 --execution-evidence 才进入既有成交证据流程。独立复盘的 --include-execution 可明确启用历史成交检查。

摘要文件被 Git 忽略。刷新摘要按钮只重新读取导出文件，不会在浏览器启动采集或训练。网站部署仍须显式提供导出的文件。

## 本地真实数据检查

本次验证使用9月21、22、23、28日的已有冻结报告，行情截至9月28日。上海时间9月30日收盘前，最近应完成交易日为9月29日，仍缺一个后续交易日。

收益主榜已有180条可对照收盘记录，平均价格误差10.25%，朴素基线7.92%，方向一致44.44%。上涨初期榜已有100条，平均价格误差5.28%，朴素基线5.28%，方向一致51.00%。这些是迟发回顾、部分窗口的描述性结果，不能证明模型或筛选方法已经有效；有效前瞻样本仍为0。

## 后续顺序

1. 先补齐每日行情更新与覆盖报告，按真实获取时间追加成熟结果。
2. 扩展价格分析：同股票同窗口的历史波动基线、价格中心和区间宽度拆解、模型分歧与误差的分组关系；保留冻结规则，避免用观察后的结果调优同一评估集。
3. 再补行业和公司信息、公告事件的来源与解释，按信息可见时间独立分析，验证是否增加研究价值。
4. 积累按时发布的前瞻样本后，评估稳定性和不同市场环境的差异，再决定是否调整默认模型或排名。
