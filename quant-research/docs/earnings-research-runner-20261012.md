# 四组离线研究入口与实际输入适配检查

后续用户已确认最低佣金5元，并要求全自动、无需人工参与。本文原人工验收与最低费待确认的描述保留为历史状态；当前方案见earnings-automatic-validation-20261012.md及交易协议v3，人工复核不再是运行依赖。

本阶段将既有候选、固定资金账户、盘前匹配、逐日核账和统计诊断串成一个可保存文件的研究入口。实际市场资料仍未验收，正式每日运行器与前瞻注册仍未实现；没有真实策略收益结果。

当前协议已按用户选择另存v2：504日唯一正式检验、至少100个成熟事件及60个成熟入场日期。入口同时支持明确指定的旧v1重现和新v2，新审计默认使用v2；版本变更不得续接旧账本。完整变更与验证见earnings-validation-v2-20261012.md。

## 已贯通的研究流程

scripts/run_earnings_experiment.py读取输入目录中的inputs.json、原方案配置、规范Snapshot和七张表：逐日冻结时钟、公告、行业历史、流通市值历史、模型排名、公告覆盖与生效费用。外层清单必须绑定所有输入文件，包含快照自身清单和七张市场表；文件路径不能离开输入包。输出目录必须为新目录，不覆盖或续跑失败尝试。

v1与用户确认后的v2各有固定语义摘要。改变佣金、事件门槛、持有期或其他规则时，入口拒绝继续；不能改配置后让未更新的实现悄然使用旧规则。佣金0.0005来自用户确认，单笔最低5元和10%回撤仍为研究假设，不据此宣称用户已确认损失承受能力。

| 账户与情景 | 输出范围 |
| --- | --- |
| P、M、E0、E1完整账户 | 原20日持有、固定20万元、六槽位和行业约束 |
| E1匹配子账户、P匹配控制账户 | 使用基础E1盘前选定的身份与目标预算；保留单边成交与现金日 |
| 基础、压力、延迟一日、5及20基点滑点 | 20日持有的五个情景，每个六组账户；压力仅加倍佣金与滑点，不加倍法定税费 |
| 5日持有 | 基础情景的六组账户，只作描述性比较 |

合计36组账户。基础匹配取盘前选定记录，不以成功成交筛选；20日压力、延迟与滑点情景沿用同一批配对，不按未来收益重新找控制股。每个观察收盘都必须有冻结时钟，包含无信号日和末尾日。缺模型排名、迟到排名或缺横截面不能伪装成现金信号。末尾候选另存pending-candidates，实际分配后的目标预算、股数、入场日保存为pending_entries，末尾配对也在收盘时形成；不制造未来成交。为冻结延迟情景，日历必须包含末日之后两个交易日。

当前入口明确只运行人工输入。training资料被拒绝，真实资料也须等待独立验收和正式运行器；人工标记不能授予任何收益资格。离线按历史收盘计算与不可改写的实时冻结还有区别，正式时钟、来源绑定、模型训练截止、历史滚动切分及单次检验登记仍需实现。

## 实际输入适配结果

scripts/adapt_earnings_inputs.py验证原market-v1/input的刷新清单、派生ID、归档实现和八个规范化捕获。原七张Parquet文件原样复制，原清单、派生说明、归档代码另存origin；新清单保留原来源时钟，并记录本轮实际转换时钟。训练用途及所有资格声明保持不变，不借格式转换补造复权因子或提升验收标志。

首个实际尝试保存于canonical-training-v1，严格加载失败：855,995条行情中的6,406条factor非有限，其余六项必要价格量额字段没有非有限值。原表字节哈希一致；失败目录保留，不续跑。初版失败收据只记录异常类型，原因已通过只读严格加载复现并写入runner-audit-v1/audit.json，旧收据未覆盖。适配器现为后续新尝试补存异常文本。

这6,406条缺失不是策略亏损证据，也不代表全部市场资料已普查。它说明当前明确选中的刷新包还不能原样成为规范账户输入。需要有来源与区间定义的资料，另行保留不可用行的排除原因；不能一律填1、跨未核实公司行动延续价格尺度或把training改为full_experiment来放行。

## 验证证据

artifacts/earnings-validation-20261012/runner-audit-v1保存人工输入、实际CLI日志、36组账户及复核结果。人工包使用190个工作日和24个虚构证券，其中31个收盘进入观察窗口；不代表真实交易所日历。共有353份账户与诊断输出绑定哈希。独立路径从保存的表核对完整日历、现金加持仓加应收款减分红税准备的净值恒等式、期末收益以及逐日配对收益差。人工数值不用于估计或预测策略收益。

runner-tests-v2.log记录本阶段69项受影响路径测试通过，其中19项新增适配与统一入口测试；其余50项为本次实际重跑的账户、匹配、候选、端到端和统计检查。覆盖未来价格/公告扰动不改变早期候选与匹配、固定配对跨情景延续、5/20日实际退出、延迟入场、滑点、佣金压力与税费分离、完整无公告输入的事件现金账户、末尾候选保留、模型缺失/迟到拒绝、配置改动拒绝、路径和文件哈希篡改拒绝，以及失败尝试不覆盖。

runner-tests-v1.log保留17项通过与2项失败：初版人工包使用的通用清单工具排除了嵌套manifest.json，入口按设计拒绝不完整包。新增人工包封存函数后，v2全组通过；没有放松入口要求。新代码的定向ruff通过。Rust与此前来源预检代码本阶段未改变，未将旧日志冒充本次重跑。
