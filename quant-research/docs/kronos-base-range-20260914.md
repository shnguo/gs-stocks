# Kronos-base 五日区间对照

状态：原生路径生成、重载复现、共同样本评价和独立核验均已完成。Kronos-base 没有在本轮五日区间任务上优于 Kronos-small；最低价误差更高。

## 冻结方案

将 Kronos-base 加入已有自建 372 万、自建 28 万、Kronos-small、历史波动及持平基线的比较。沿用此前最高价、最低价、振幅的 MAE 和 CRPS，80% 区间覆盖与评分，上下 2%/5% 触及概率，以及日线可识别的极值先后顺序。

模型为 [NeoQuasar/Kronos-base](https://huggingface.co/NeoQuasar/Kronos-base)，固定版本 2b554741eca47781b64468546e77fef3e85130e6。模型预测主体有 102,310,592 个参数，另有 416 个固定旋转位置编码值；官方权重文件合计 102,311,008 个数值。12 层、隐藏维度 832、16 个注意力头。权重从镜像下载，与[官方 SHA256](https://huggingface.co/NeoQuasar/Kronos-base/blob/main/model.safetensors)核对一致；使用旧实验已固定的官方 tokenizer 和推理代码。

输入仍为 60 日历史 OHLCVA 与日历，生成 32 条五日路径，温度 1、top-p 0.9、top-k 0、裁剪范围 5。调用原生推理，将独立样本放在批次轴，内部样本平均轴长度为一，避免把多条路径平均成一条。批次含四条输入，每批固定种子为 17 加起始行号，不根据结果重新采样。

生成覆盖此前三模型交集的全部 1,510 条股票日期记录，不根据未来结果选择输入。评价时保留原先的 1,349 条完整标签共同样本，再要求 base 至少有八条合法完整路径；所有模型均在最终交集重新计算指标，并披露被排除的记录。历史波动基线沿用此前已经固定的路径。

误差以信号日收盘价的百分比点计量，先按同日股票平均，再按八个日期等权。差异区间沿用 2,000 次两日期连续区块重采样；这是单个已研究开发窗口上的事后诊断，不作多重比较校正，不代表稳定或未来优势。没有微调 base，没有读取封存标签，没有执行交易回测。

## 已完成的生成与覆盖

Base 对全部 1,510 条输入生成 48,320 条五日 OHLCVA 路径，推理约 17.6 分钟。37,213 条路径满足完整五日价格和成交量/金额合法性条件，1,473 条输入至少有八条合法路径。

此前完整标签且其他模型均可预测的 1,349 条记录中，有两条不满足 base 最低路径数要求，最终共同评价为 1,347 条，仍覆盖八个日期。两条排除记录在 availability.parquet 中保留。所有旧模型的指标都按这 1,347 条重算；因此与上一次 1,349 条表格略有差异，不能直接把旧表数值搬过来。

## 极值和振幅中位数误差

以下误差越低越好。单位为信号日股价的百分比点，例如 10 元股价对应 3.96 的误差比例约为 0.396 元。这不是预测正确率或交易收益。

| 模型 | 最高价 MAE | 最低价 MAE | 振幅 MAE |
| --- | ---: | ---: | ---: |
| Kronos-base，约 1.02 亿参数 | 3.9592 | 3.0991 | 4.0915 |
| Kronos-small，约 2474 万参数 | 3.9357 | 2.8708 | 3.9706 |
| 自建 372 万参数 | 4.1041 | 2.7193 | 3.8933 |
| 自建 28 万参数 | 4.0335 | 2.9068 | 3.5638 |
| 历史波动基线 | 4.0437 | 2.1986 | 4.5072 |
| 持平基线 | 5.0634 | 3.0609 | 8.0452 |

相对 Kronos-small，base 的最高价 MAE 高 0.60%，最低价 MAE 高 7.95%，振幅 MAE 高 3.05%。相应的绝对误差差值条件 95% 区间为 [-0.0561, +0.1061]、[+0.0994, +0.3622]、[-0.0055, +0.2881]。最低价退化在本轮区块区间下较明确，其余差异跨零。区间未作多重比较校正，且只有八个已研究日期，不等于普遍退化。

相对自建 372 万参数模型，base 的最高价 MAE 低 3.53%，但最低价 MAE 高 13.97%，振幅 MAE 高 5.09%；三项 MAE 差异区间均跨零。Base 的最低价 MAE 甚至略高于持平基线；这仅是本轮点估计，不能概括为所有预测维度都不如持平。

## 核验完成

- 权重严格载入并核验 SHA256；首批 128 条路径在重新载入权重后复现。
- 修改历史 token 后缀，核验前缀 40,960 个 logits 不变，验证 base 推理的因果性。
- 所有模型在共同样本上的历史归一化输入逐项一致。
- 旧五个模型合计 20,205 条行/目标分数与前次保存值逐项一致。
- 独立核验全部 24,246 条行/目标分位数记录、实际五日极值、MAE、区间覆盖与评分、日期等权差值；另用独立公式重算 base 的 4,041 条 CRPS。
- 七项相关指标测试通过，新增脚本 Ruff 通过。

早期 v1 在生成前把权重文件总元素数误当作参数数，计数断言失败；严格权重加载已通过。v2 区分了 416 个固定缓冲值，模型与采样设置未变。失败记录保留，没有在看到预测结果后换权重或重采样。

本轮不支持用 base 替换 small 或自建模型。结论限于本地五日任务、60 日历史、冻结采样设置与这个开发窗口；不是对其他历史长度、微调方式或市场的结论。Kronos 检查点的精确预训练日期清单仍缺少独立认证，封存标签保持未读。
