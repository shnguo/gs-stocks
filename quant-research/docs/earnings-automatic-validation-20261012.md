# 全自动数据验收：最低佣金确认与自动拒绝

用户确认每笔最低佣金5元，并明确系统应全自动、无需人工参与。已创建交易协议v3，保留原v1/v2及已有结果。资金20万元、佣金0.0005、六槽位、20日主要持有、100个成熟成交事件、60个成熟入场日和504日唯一正式检验均不变。10%回撤仍为研究假设；券商名称及佣金是否包含规费仍未核实。

之前要求用户或同事完成100份人工复核，是方案额外引入的依赖，现已撤销。旧复核包仅保留为历史工程记录，不需要填写。无人工参与应通过严格限制可处理范围实现：遇到不确定输入，系统自动排除并记录原因，不把人工任务留在队列中。

## 自动通过的完整条件

1. 原PDF、证券身份、报告期和实际观测时钟有不可变来源绑定。
2. 两条不同的提取实现对同一原件的归母利润口径、金额单位、利润上下界、正基期和原文披露同比达成逐字段一致。可采用PDF确定性解析与另一PDF/OCR实现，或已核实单位、版本与来源的结构化数据交叉检查。同一解析器重放、换提示词或两次模型自报置信度不能计为第二实现。多路一致仍有共同错误风险，不等于已量出准确率。
3. 披露同比与利润和上年同口径金额在原文舍入精度内相容。缺同比直接排除，不用计算值补成原文披露值；冲突不选择更有利的一组。
4. 原件与完整前序、更正链能证明该公司报告期的首次数值信息；旧公告本地迟采仍为迟采。无法证明历史公开时钟，只从实际本地首次观测参与后续研究。
5. 风险状态、停牌、涨跌停、证券身份、公司行动、费用与订单时效均通过对应来源与有效区间检查。对照组也需完整公告覆盖，漏采不能充当没有事件。

单个事件不满足条件时自动排除；账户级行情、估值或执行资料不完整时禁止新订单，并保留已有持仓、应收款与未知/陈旧估值，不能记录成持有现金。数据恢复后不得补造过去决策。策略回撤暂停只阻止新入场，不能把无法卖出的持仓删除。

固定100份原文用于开发期自动失败模式和覆盖诊断，与正式检验要求的100个成熟公司×报告期成交事件不同。35%的当前算术通过比例不能外推到全市场信号可得性；必须实际检查504日期间能否取得100事件和60入场日，样本不足仍判未建立优势。

## 第一阶段已实现（后续第二路径进展见下）

生产金融校验由Rust持有：mootdx-cf的earnings_numeric_checks.rs新增舍入算术检查；research-cninfo-earnings-auto-check入口重核捕获清单、原始分页、PDF及派生文本哈希，按原解析器重新提取并逐记录比较，再执行自动筛查。它是自动验收中的第一块，不是完整的第二提取路径。

每个金额的允许舍入宽度取原文最后一位的一半，按对应单位换算；同比也保留原文百分比精度。基期及本期金额经区间除法重算许可同比区间，不使用统一“误差1个百分点”的宽松阈值。机器候选、可见时钟和原件均没有被修正或覆盖。

新的preflight-v6绑定419个来源文件，human_review_required为false；最低5元为用户确认值，券商完整费用项目仍待核实。20项来源/运行条件尚未完成；原文关口现在要求自动多路语义验收，不再要求人工。全部自动财务、首次数值、历史及时性、正式收益和前瞻注册资格继续为false，当前合格历史信号0。
