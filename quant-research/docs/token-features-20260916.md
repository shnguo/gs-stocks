# Token 模型的换手率与估值输入

## 本轮结论

已完成四组等预算训练及 577,792 条五日路径预测。单种子、71 个评估日期的结果如下：高低价误差综合二日/五日最高与最低价，正值表示比基线更差。

| 输入 | 高低价平均误差变化 | 误差改善日期占比 | 收益率预测 MAE | 排名前 20% 的极值场景值 |
| --- | ---: | ---: | ---: | ---: |
| 原模型 | 基线 | — | 4.3703 个百分点 | 10.10% |
| 加换手率 | +0.0070 个百分点 | 49.3% | 4.1290 个百分点 | 9.39% |
| 加估值 | +0.0098 个百分点 | 52.1% | 4.4783 个百分点 | 9.33% |
| 两者同时加入 | +0.0325 个百分点 | 45.1% | 4.4149 个百分点 | 9.43% |

换手率版本的收益率预测误差下降 **5.52%**，是值得保留的局部改善；但本轮抽样选股的极值场景值没有提高。估值版本在多数评估日期改善，但部分日期的退步幅度更大，平均误差略增。两类特征同时加入也没有出现整体优势。以上改善频率不是未来有效概率。

保留全部候选 checkpoint 和比较入口，当前每日模型继续使用原版本。这不是根据单个退步分组或显著性阈值否定新特征：当前约三分之二历史格点缺失、连续均值特征完全不可用，下一步有价值的补充是连续且可核实版本时点的数据；本轮未自动启动新补采或进一步训练。

极值场景值按预测时已选定的卖出日，在真实日线中计算该日最高价 / T 日最低价 − 1 − 0.25%。它不代表能够成交或已实现的收益。

## 实现范围

现有六项行情 tokenizer 和五日行情 token 输出保持原协议。新增历史特征残差分支，与每个历史交易日的 token 表示相加；模型自行学习权重，不添加买卖规则。

四个版本：baseline、turnover、valuation、both。配置保存特征名称和顺序，checkpoint 保存仅由训练数据计算的均值和标准差；零初始化的残差输出使扩展模型在首次更新前与原 checkpoint 的输出完全相同。

- 换手率：log(1 + 成交量 / 当日流通股数 × 100)、一日/五日差、相对 5/20 日均值。
- 估值：E/P、五日/二十日 E/P 差、负 PE 标记。PE 为零或缺失时 E/P 缺失；不计算跨零点不稳定的 PE 百分比变化。
- 缺失输入使用显式可用标记。标准化值截断至 ±5，属于输入变换，不是交易规则。
- 相对均值必须有完整连续交易日；五日差必须匹配五个交易日前的实际数据。禁止以前五条稀疏记录代替五个交易日，禁止前向填充。

## 信息边界

训练损失和生成接口只接受 60 日历史特征。训练时即使未来行情 token 用于 teacher forcing，未来的辅助特征仍被设为缺失；生成时每新增一天同样追加缺失特征。训练与预测遵守相同边界。

前向数据入口要求带时区的 available_at 证据，晚于对应历史交易日上海 16:30 的数据保持缺失。该字段必须代表数据版本当时已可获得，不能用采集时间冒充。研究模式允许已有回溯源，但会明确标注 retrospective。

现有旧研究数据 371 个日期、1,745,942 条来源记录具有原始归档和哈希；不具备原始财务版本的时点认证。本次复用冻结数据，不修改旧研究的封存日期规则。

## 手动运行

从任意目录执行：

    /Users/guo/Documents/stocks/quant-research/scripts/run_token_features.sh

该命令依次完成数据校验、特征生成、四组等预算继续训练、五日路径预测及报告生成。仅准备数据可追加 --prepare-only。已完成输出会校验后复用，不重复训练。采用既有本地 Python 环境，不安装或启动定时任务。

参数文件：configs/token-features-v1.json。不同实验需要指定新的 output 目录，避免覆盖原始证据。模型文件在对应输出的 seed17/版本/model.pt。支持三个历史种子，但默认先运行单一种子的有限比较。

日常手动盘后入口 scripts/run_daily_token.sh 继续使用当前模型。特征实验不会替换每日 checkpoint 或最新报告指针。当前实时特征数据尚未完成时点与连续性认证，不能将回溯实验直接包装成盘后模型已启用新特征。

## 冻结比较方案

- 所有版本从同一历史 midpoint checkpoint 初始化，原模型也执行相同继续训练。
- 训练：2020–2023 年、251 个有源快照的交易日、7,969 行；每组固定 4 轮，使用相同随机顺序。
- 验证：2024 上半年、45 日、716 行，只报告 CE，不按结果修改训练预算。
- 评估：2024 下半年至 2025-07-22、71 日、2,257 行。分界前完整隔离五日标签。
- 现有等权五日 token CE + 0.05 midpoint 损失、冻结 decoder、64 条采样路径保持一致。
- 仅使用训练历史拟合特征标准化。不按特征是否缺失筛掉股票；四组使用相同输入队列。
- 主要指标为二日/五日最高价和最低价误差，按股票后按日期平均；配对公共有效样本，另保留各组合法路径覆盖率。
- 汇报逐日改善比例、两个时期 × 两个期限 × 两个极值的八种场景、日期块 bootstrap 区间；局部退步或区间跨零不自动否定总体改善。
- 排名严格使用卖出参考价 / 买入参考价 − 1 − 0.25%。买入参考为 T 日低价中位数，卖出日为路径最高价日期的众数（并列取早），卖出参考为该日高价中位数。
- 排名评估冻结预测卖出日，再计算真实该日高价 / 真实 T 日低价的极值场景值；不是成交回报。每日期只在抽样股票中比较前 20%，不称为全市场选股效果。

## 数据限制

目前训练历史特征格点约三分之一有源快照。信号日核心特征覆盖率较高；5/20 日均值特征覆盖为零，一日变化也很少。代码已支持这些维度，但本轮无法检验连续均值特征的价值，需补充连续原始快照并重新拟合标准化后再评估。

数据源为回溯版本、评估日期已被旧研究使用、tokenizer 预训练日期重叠未完全解决。本次是有限单种子继续训练实验，不能宣称时点无偏或证明未来盈利。

## 验证

覆盖零残差初始一致性、非零梯度和特征敏感性、checkpoint 精确重载、因果注意力、未来特征拒绝/缺失、真实交易日偏移、停牌/缺失不补值、零/负 PE、可用时间约束，以及原模型、损失和日常脚本回归。

当前验证：58 项测试通过，1 项因通用测试环境缺少官方 tokenizer 依赖而跳过；实际实验使用已固定的 Kronos 环境和真实 decoder。另已核对真实 3,720,448 参数父模型：新旧代码两头输出、零残差扩展初始输出均完全相同。手动入口的并发互斥检查也已通过。

独立核验通过：14,670 条原始特征记录、16 个输入的 64 路径精确重放、8,692 条参考价排名、1,136 项逐日高低价评分；每日原运行 manifest 哈希保持一致。已完成实验再次手动执行只校验并复用结果，不重复训练。详见 [核验记录](../artifacts/token-features-20260916-v1/verification.json)。
