# 收益校准模型更新

## 实现

保留已有技术指标与收益/排序损失 Transformer，在输出端增加一个可训练的收益校准层。输入为原始预测收益、过去 20 个交易日的复权收盘价波动率及二者交互；输出为收益预测误差的估计。参数从已成熟标签拟合，没有统一减去固定百分比，也不按波动率排除股票。

校准层使用带正则项的线性回归，四个可学习系数。它是附加预测组件，本次没有重新训练 Transformer 主干或改变 OHLCVA token 生成。每日已有的 Transformer 增量训练继续按原流程执行。

原始参考价测算收益与校准后预期收益是两个字段。校准后的排序不再等于原始参考价格直接相除；报告同时保留两者、买卖日期和原始买卖价格，不反向修改价格来凑收益。

## 固定验证方案

- 原始证据：token-three-ideas-20260917-v1 中 indicators_ranking 的全部有效预测。
- 固定岭回归系数 0.01，不搜索特征、参数或随机种子；训练时每个日期总权重相同。
- 至少 20 个已有成熟标签的日期才开始预测；整段五日标签必须结束于信号日之前。
- 原始 71 个日期中，22 个作为起步阶段，49 个用于逐日向前比较。每个日期重新拟合此前可见结果。
- 三个随机种子和组合分别拟合；在各自全部可预测股票上训练，同一校准层同时评估原始股票池与四组实验共同股票池。
- 缺失标签不改变 Top20，不以更低排名补位。保存每个日期的模型、排序及校验清单。
- 独立校验使用增广最小二乘重新求解参数，检查完整排名、日期隔离、参考价格、选定退出日期与指标。
- 这些日期已经用于前期研究，本次属于开发验证，不是新保留测试集。

## 结果与使用决定

全部可预测股票、相同 49 个日期：

| 模型 | Top20 平均情景收益改善 | 改善日期 |
| --- | ---: | ---: |
| seed 17 | +0.3373 个百分点 | 33/49 |
| seed 29 | +0.8509 个百分点 | 31/49 |
| seed 43 | +0.1596 个百分点 | 28/49 |
| 组合 | −0.2152 个百分点 | 21/49 |

组合模型 Top20 平均高估从 5.90 降至 3.58 个百分点；固定原始 Top20 不换股时，高估降至 2.18 个百分点。三个单模型的平均绝对误差均下降；组合从 3.6520 微升至 3.6706 个百分点。组合 Top20 平均情景收益 12.94% → 12.72%，高波动组占比 95.3% → 99.3%。因此减少收益高估并不等于解决高波动集中，也不等于组合选股收益提升。

共同股票池下，三个单模型平均收益改善分别为 +0.1858、+0.7700、+0.0349 个百分点，改善日期分别 28/49、32/49、26/49；组合 −0.0756 个百分点、23/49 日期改善。正面证据保留，不根据结果挑选某个种子替换默认组合。

当前决定：保存训练完成的四个收益校准层，接入手动流程的候选报告。主模型和主报告指针保持现有版本；组合校准排序尚不足以替换默认排序。

上述情景使用实际 T 日最低价买入、预测选定日期最高价卖出，扣除 0.25% 成本，不代表实际成交或已实现收益。

## 手动使用

在 /Users/guo/Documents/stocks/quant-research 下执行 scripts/run_daily_token_matched.sh。

该入口按顺序完成：行情校验、主模型增量训练与报告、匹配的收益/排序损失模型增量训练、校准候选报告及成熟结果复盘。没有增加任何定时任务。

如仅需对已有匹配模型输出生成校准候选报告，可使用：

PYTHONPATH=src:scripts artifacts/kronos-comparison-20260910-v1/venv/bin/python scripts/token_return_calibration_daily.py

该命令默认读取匹配模型当前指针；不是主模型的当前指针。两条模型链可能对应不同日期，候选报告以自身数据日期为准。历史补发报告明确标记，并排除在前向评分和新增监督样本之外。

后续手动运行时，只有此前开盘前发布、五日结果已成熟的原始预测可以加入校准训练。每次从固定历史预测与全部可用成熟前向样本重新拟合这个小型校准层，不重复累加梯度。留存训练来源与样本计数。历史校准向增量训练模型迁移仍需继续观察。

验证可使用：

PYTHONPATH=src:scripts artifacts/kronos-comparison-20260910-v1/venv/bin/python scripts/token_return_calibration.py

已完成版本会校验并复用，协议或代码发生变化则要求新输出目录。最终模型只供其训练标签结束之后的日期使用。
