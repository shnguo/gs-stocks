# 美股动量与反转因子检验（2026-11-06）

> 已被 [第二版](us-factor-momentum-value-20261106.md) 取代：第二版加入了重建的罗素 1000 和价值因子。

## 结论

股票池是标普 500 与纳斯达克 100 的历史成分股并集，每月约 520 只。时间跨度为 2016 年 1 月到 2026 年 9 月，按月调仓。

- **12-1 月动量在美股大盘股里几乎没有效果**：117 个月的 Rank IC 均值 0.006（t = 0.33），95% 置信区间 [−0.020, 0.034]。最高分组（Q5）扣费后每年只比股票池等权平均多 0.3%。
  - 2021 年动量大幅回撤，多空组合 −19.5%，原因是成长股向价值股的风格切换。
  - 2023 到 2024 年动量重新有效，多空组合每年约 +13%。
- **1 个月反转同样接近零**：IC 均值 0.007（t = 0.45）。
  - 2016 到 2019 年反转有效，IC 约 +6% 到 +8%。
  - 2023 年以后方向反过来了，2025 年多空组合 −18.6%。也就是说，最近几年大盘股上个月的强势股，下个月反而继续强。
- **单看纳斯达克 100**，动量稍强：IC 0.020（t = 0.92），多空组合年化 6.1%，但仍不显著。反转在这个股票池里是负的。
- **和 A 股对比**：A 股的 1 个月反转显著有效（IC 0.052，t = 3.98），美股大盘股里看不到。两个市场里 12-1 动量都无效。

## 方法

| 项目 | 设定 |
|---|---|
| 股票池 | 每个月末是标普 500 或纳斯达克 100 成分股、且当天有成交的股票 |
| 标普 500 成分股 | GitHub `fja05680/sp500` 的历史成分股数据，固定在提交 `a2430f2a`，代码为当天实际使用的代码 |
| 纳斯达克 100 成分股 | 维基百科当前成分股（页面版本 1381716526）加上历史变动记录（版本 1379454387），从现在往回倒推 |
| 价格 | Alpaca SIP 日线，按拆股和分红复权；每段成分股记录用它最后所在月份的代码去查询，改名的股票能拿到完整历史 |
| 合并 | 同一家公司如果在两个名单里代码不同（例如 FB 和 META），根据价格序列完全一致合并成一个；价格中间断档超过 20 个交易日的，当作两段，收益不跨越断档 |
| 调仓与成交 | 月末出信号，次日开盘买入，下一个月末的次日开盘卖出；中途退市的按最后成交价计算 |
| 动量 / 反转 | 与 A 股研究相同：动量取过去第 252 到第 21 个交易日的收益，反转取最近 21 个交易日收益的负数 |
| 评价 | Rank IC、五分组等权收益、多空组合、Q5 相对股票池等权的超额；置信区间用 6 个月分块 bootstrap |
| 成本 | 单边 0.05% × 换手率 |

数据覆盖：803 段成分股记录全部拿到了价格，对应 776 家公司、186 万条日线。每个月的成分股里有 0 到 13 只当天没有成交（主要在 2016 年初，Alpaca 的数据从 2016-01-04 开始）。

| 股票池 | 因子 | IC 均值 | t 值 | Q1…Q5 月均收益 | 多空年化（扣费前 / 扣费后） | Q5 超额年化（扣费后） |
|---|---|---|---|---|---|---|
| 并集（约 520 只） | 12-1 动量 | 0.006 | 0.33 | 0.98 / 1.06 / 1.08 / 1.07 / 1.15% | 0.5% / −0.1% | 0.3% |
| 并集 | 1 月反转 | 0.007 | 0.45 | 1.11 / 1.13 / 1.15 / 1.13 / 1.18% | −0.3% / −2.1% | −0.7% |
| 标普 500 | 12-1 动量 | 0.006 | 0.29 | 0.99 / 1.09 / 1.09 / 1.03 / 1.16% | 0.3% / −0.2% | 0.4% |
| 标普 500 | 1 月反转 | 0.008 | 0.50 | 1.10 / 1.14 / 1.13 / 1.15 / 1.18% | −0.2% / −2.1% | −0.7% |
| 纳斯达克 100 | 12-1 动量 | 0.020 | 0.92 | 0.83 / 1.31 / 1.39 / 1.20 / 1.62% | 6.1% / 5.5% | 2.6% |

股票池等权组合本身年化 11.8%，波动率 17.8%，最大回撤 −30.5%。

## 局限与下一步

- **还没有罗素 1000**：计划按指数规则重建，即每年 6 月按市值取前 1,000 只。这需要 SEC 的流通股数据，而 SEC 要求请求带联系邮箱，目前还没拿到。
- **还没有价值因子**：同样需要 SEC 的财报数据。会按财报实际提交日期对齐，只使用当时已经公开的数字。
- 标普 500 名单来自社区维护的数据集；纳斯达克 100 是从维基百科变动记录倒推的，个别早期改名的代码可能对应不准。
- 等权五分组，没有考虑冲击成本和做空成本。
