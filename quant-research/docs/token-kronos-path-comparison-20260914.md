# 自建行情 Decoder 与 Kronos-small 的直接路径对照

补充：[五日最高价、最低价、振幅及顺序对照](token-range-comparison-20260914.md)已完成。该报告加入历史波动基线，避免仅以收盘误差评价波段用途。

结论：本次共同样本上，自建 372 万参数模型与冻结 Kronos-small 各有优劣，尚无证据判定谁稳定更好。两者的收盘中位数预测均未胜过持平基线。此前容量实验只比较两个自建模型，本报告补上与 Kronos 的直接价格预测对照。

## 对照范围

复用已生成且经复核的原始路径，不重新训练、采样或调参。Kronos 使用本地已固定版本的 NeoQuasar/Kronos-small 预训练预测主体，共 24,741,696 个参数；自建预测主体分别为 3,720,448 和 281,936 个参数，从头训练。三者共用冻结官方 tokenizer，参数数目均不包含 tokenizer。此实验比较三套具体模型，不能把差异单独归因于架构或容量。

三者均使用 60 日 OHLCVA 历史，采样 32 条五日路径，温度 1、top-p 0.9、top-k 0。保留原实验的随机路径，不要求三个模型随机数逐项相同。两个原始证券集合各有 1,534 条股票日期记录；按股票身份与信号日连接，共 1,510 条，覆盖 2025-06-03 至 2025-07-22 的八个日期。两侧证券集合的预先选择时点不同，因此使用交集且披露损失的覆盖，未根据预测误差选样本。

已逐项核对两套缓存中共同样本的全部历史值、复权锚点、历史均值和标准差完全一致，未来标签及结束日期完全一致。三个模型均须至少有八条合法完整路径，才进入共同价格指标：共 1,431 条满足条件，第五日收盘标签已知的为 1,349 条。

## 第五日收盘结果

误差按各股票历史收盘价标准差加 1e-5 归一化，按日期等权；数值不是收益率。MAE 衡量中位数价格误差，CRPS 衡量整个预测分布误差，二者越低越好。区间覆盖率应接近标称的 80%。

| 模型 | 中位数 MAE | 分布 CRPS | 80% 区间实际覆盖 |
| --- | ---: | ---: | ---: |
| 自建 372 万参数 | 0.76289 | 0.58649 | 72.89% |
| 自建 28 万参数 | 0.85496 | 0.66354 | 56.45% |
| Kronos-small，2474 万参数 | 0.74738 | 0.60298 | 61.71% |
| 持平基线 | 0.62009 | 0.62009 | 无区间 |

372 万参数模型相对 Kronos-small：分布 CRPS 低 2.73%，中位数 MAE 高 2.08%。两日期连续区块、2,000 次固定种子重采样的条件 95% 区间分别为 [-0.07992, +0.03273] 和 [-0.05421, +0.07355]，均跨零，不能据此宣布胜出。小模型两项点估计均更差。

所有模型中位数 MAE 均高于持平基线；自建大模型和 Kronos 的分布 CRPS 则低于确定性持平预测。这两个指标回答的问题不同，不能据单项指标概括为全面有效或全面无效。当前无模型晋级或每日模型替换。

本表重新取三个模型共同样本，因此数值与之前仅两个自建模型的 1,373 条共同样本结果略有不同。

## 路径覆盖

以下统计基于 1,510 条身份日期交集，每模型共 48,320 条路径。合法要求整条五日路径均有限、价格为正、成交量及金额非负、高低价关系成立；不修补非法路径。

| 模型 | 合法路径数 | 至少八条合法路径的股票日期数 |
| --- | ---: | ---: |
| 自建 372 万参数 | 41,539 | 1,451 |
| 自建 28 万参数 | 42,752 | 1,449 |
| Kronos-small | 38,222 | 1,469 |

价格误差仅对共同可预测且标签已知样本成立，不能隐去路径筛选条件。

## 证据与边界

这是单个已研究开发窗口上的事后对照；八个日期不支持稳定优越性结论。自建模型有本地监督训练，Kronos 为未针对本轮微调的预训练模型；Kronos 检查点的精确预训练日期清单仍未独立认证。未读取封存标签，也未补算 Kronos 的全群体 token 交叉熵。

来源哈希核对、历史与标签一致性核对、路径合法性重算全部通过。全部 30 个日/字段组合均计算；每条可评价记录的 CRPS 使用两两路径距离公式，并与排序公式独立核对。分析脚本 Ruff 通过。
