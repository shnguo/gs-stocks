# P0 现有数据与替代 ST 证据核验

核验日期：2026-09-07，北京时间上午。对象为本机 Tushare 账号和已配置的 Cloudflare 预览数据湖，外部访问均为只读。

结论：现有替代数据尚不能认证为十年、全 A 股、逐日完整的 ST 历史。用户随后允许 ST 纳入训练，当前默认训练范围已包含 ST、*ST 和未知状态；ST 完整性改为辅助审计与非 ST 组合回测的依赖。多年行情、退市身份、复权/公司行动等其他缺口仍需补齐，正式全市场实验尚未就绪。

## 名称变更的使用边界

官方 namechange 提供名称、生效区间和公告日期，没有精确公告时分秒，也未将接口定义为完整风险状态流。[Tushare 官方字段](https://tushare.pro/document/2?doc_id=100)

名称带 ST、*ST、SST、S*ST 可形成风险候选；普通名称只形成普通状态候选。不能把缺少风险记录解释为当日一定正常，也不能根据今天的名称覆盖过去的状态。

官方代码仓库中有批量与逐股 namechange 不一致的公开问题报告。这是用户报告，未被维护者确认，不能直接断言本账号数据有该问题；它提示需要独立交叉核验。[Tushare 问题 #1901](https://github.com/waditu/tushare/issues/1901)

新增 Rust 解析器保留有效日期和公告日期，识别旧式 ST 前缀，报告日期缺失、公告晚于生效、重叠及断裂区间，排除混入的 B 股并留下清单。结果固定标为候选，不认证历史完整性。

## 后续依赖

1. 优先补齐退市证券、历史代码映射和逐年预期证券池；训练范围不再等待完整 ST 史。
2. 补齐长历史日历、行情、因子、公司行动、限价和费用版本，处理停牌及退市导致的执行端点缺口。
3. ST 来源保留辅助任务：核验已有深市名称候选，限额允许后留存其他市场名称分页及独立公告；缺少证据的日期保留 unknown。
4. 非 ST 模拟组合单独核验状态覆盖和执行前风控；训练验收不代表这部分已完成，不伪造 ST 可用时刻。
5. 数据验收通过后再执行多年滚动训练；当前不得发布正式策略表现。

没有付费开通接口、部署服务、修复线上日历或开始实盘交易。
