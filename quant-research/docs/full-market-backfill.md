## 恢复与验收

Rust 命令负责采集、金融字段解析、原始响应重放和任务状态。计划及每次采集使用独立哈希，重启前重建计划并核对完整目录；已完成且通过原始响应复验的任务直接跳过。

每个任务在网络请求前写入尝试记录，防止网络中断被误当成未执行任务。进程锁限制同一队列只有一个采集进程；进程退出后操作系统释放锁。失败与中断任务不自动重试。人工核验后，可通过 retry 命令授权一个新采集路径，原失败目录、原始字节和审查原因全部保留。

单次运行有明确任务预算，默认操作使用 500 毫秒任务间隔；Tushare 请求至少间隔 2 秒。短暂传输失败可以留痕后继续其他待采任务，连续三项传输失败则停止。解析或完整性错误会停止批次，修复并验证后才能继续。

来源拒绝权限或频率时，按来源和接口保存暂停记录。后续运行复用暂停状态，继续其他可用接口；不会用重启流程突破限额。来源恢复需要单独核验，单个任务的 retry 命令不能绕过接口暂停。

以下是独立本地队列的工程命令，在 mootdx-cf 目录执行，路径均为示例。当前全市场批次已标记 cloud-managed，run 和 retry 会拒绝在本机重复采集；日常进度及恢复应使用云端命令。新建计划和输出不能覆盖旧目录：

    cargo run --locked -- research-backfill-init /path/to/catalog/manifest.json /path/to/new-campaign
    cargo run --locked -- research-backfill-run /path/to/campaign 600 500 /path/to/env-file
    cargo run --locked -- research-backfill-inspect /path/to/campaign
    cargo run --locked -- research-backfill-retry /path/to/campaign JOB-ID '完整写明已经核验的失败原因和重试依据'
    cargo run --locked -- research-backfill-import /path/to/new-campaign /path/to/previous-campaign

账号凭据只由环境文件读取，不进入任务计划、日志或响应产物。inspect 在采集进程退出后运行，生成新的完整状态报告。

## 本轮发现并处理的问题

| 情况 | 实际处理 |
| --- | --- |
| 沪市某请求只收到部分压缩响应 | 作为失败保存，未接受截断数据；核验后使用新路径重试成功，旧文件保留 |
| 旧代码 000022 的 2018-12-26 明确停牌，所有量价字段为空 | 原始记录按无价格停牌证据保留；规范导出写入审计，不填 OHLC、不创建虚假日线 |
| 各股票采集起止日随上市和终止区间变化 | 规范导出接受交易日历范围内的逐股子区间，仍拒绝日历范围外数据 |
| Tushare 复权因子请求返回每小时 1 次的账号限制 | 保存拒绝响应并暂停该接口的剩余任务；沪深来源和北交所日线继续 |
| 北交所交易日历接口返回成功但空表 | 记录为日历缺口，未复制沪深日历或认证北交所完整性 |
| 北交所官方代码映射页面本机请求返回 403 | 失败响应保留，未推断改码日期或伪造完整映射 |

北交所独立探测取得 920000.BJ 从 2021-01-04 至 2026-09-04 的 1,376 条日线和相同数量的因子。Rust 已验证字段、日期、代码、OHLC 及单位；来源没有提供明确停牌和 ST 状态时保持未知。该样本只证明接口能够返回历史数据，不能证明北交所历史上市归属、改码和全市场因子均已完整。

Tushare 文档说明日线不包含停牌期间记录，成交量以手、成交额以千元返回，规范解析分别转为股和元。[日线接口说明](https://tushare.pro/document/1?doc_id=27)。实际账号限额以已保存的拒绝响应为准。[权限说明](https://tushare.pro/document/1?doc_id=108)。

另已核验 AKShare 使用的新浪后复权因子入口，可以返回 bj920000 的 10 条因子记录。但与 Tushare 的 1,376 个交易日对照后，归一化曲线最大相对差约 0.17525%，单日因子变化最大差约 9.903 个基点；未直接替换已暂停的 Tushare 因子任务。应核对各次分红、送转及计算方法后再决定采用。[差异记录](../artifacts/full-backfill-bse-factor-crosscheck-20260907-v1.json)、[原始响应](../artifacts/full-backfill-bse-sina-factor-probe-20260907-v1/manifest.json)、[AKShare 上游实现](https://github.com/akfamily/akshare/blob/main/akshare/stock/stock_zh_a_sina.py)。
