## 来源与独立核对

协议根据 [BaoStock 官方 SDK 0.9.3](https://pypi.org/project/baostock/) 核验，使用公开匿名查询。生产采集、金融字段解析与研究规范表导出均在 Rust 中；Python 只做研究训练和独立离线对账。没有把 BaoStock 加入研究锁文件，也没有改变全局 Python 环境。

连接固定为官方 SDK 的 public-api.baostock.com:10030。请求日期、代码、页数、响应大小和超时均有限制；EOF、拒绝、字段错位、重复记录及缺少末页均失败退出。未压缩响应核对 CRC32 和字符长度，压缩响应检查 zlib 校验与解压长度，额外外层 CRC 保留原始值但未声称其算法已核验。所有原始帧另算 SHA-256。导出前重放原始页，验证解析结果与保存记录完全一致。

| 核对 | 结果 |
| --- | --- |
| Rust 与官方 SDK 日线 | 2,675 行逐字段一致 |
| Rust 与官方 SDK 日历 | 4,022 行逐字段一致 |
| Rust 与官方 SDK 复权事件 | 30 行逐字段一致 |

| 招商银行 BaoStock 与 Tushare OHLC | 2,675 天完全一致 |
| 成交量 | 换算为股后，仅存在浮点舍入差异 |
| 成交额 | 最大差 130 元，最大相对差约 2.86×10⁻⁸；371 天差额超过 1.01 元，原始差异保留 |
| 复权曲线 | 起点归一化后最大相对差约 0.0091%；单日因子变化最大差约 1.59 个基点，尚未认证为完全相同的财富收益口径 |

[完整对账及输入哈希](../artifacts/p1-long-history-crosscheck-20260907.json)。可重新执行 scripts/verify_long_history.py，输出须使用新路径。因子仅按不晚于行情日的生效事件向前延续；没有历史锚点时拒绝导出，禁止用未来因子回填。

BaoStock 按日全市场接口还在独立探测中返回了 2016-09-01 的 2,915 行；目前仅为 SDK 读源验证，尚未实现这一路径的 Rust 批量回补。北交所 bj.920000 探测返回错误码 10004011，不能用此来源宣称覆盖北交所。

## 身份与完整性冲突

Tushare 339 条退市记录含 5 条北交所、334 条沪深记录。与 BaoStock 337 条沪深失效证券比较，有 333 个共同代码。

- Tushare 独有 T600018.SH 上港集箱历史记录。保留此前缀，不剥掉 T 后并入今天的 600018.SH。
- BaoStock 独有 600849.SH、000022.SZ、000043.SZ、300114.SZ 的失效记录。其中 300114 已核实为 2025-02-17 改为 302132，不能据旧代码失效推断公司退市。[港交所正式通知](https://www.hkex.com.hk/-/media/HKEX-Market/Services/Circulars-and-Notices/Participant-and-Members-Circulars/SEHK/2025/cc_SEHK_CTCSC_015_2025.pdf)
- 600680.SH 与 600799.SH 的终止日期存在来源冲突，见完整对账文件。尚未自动选择或合并。
- Tushare bse_mapping 当前账号无权限。官方字段中的 list_date 是上市日期，不能充当改码生效日期。

本轮新增 Tushare stock_basic、trade_cal、adj_factor、bse_mapping 规范解析与完整性提示。历史身份总表仍待补齐。当前训练导出的身份使用代码和上市日期组成临时上市实例标识，并明确未通过全历史身份验收。

已核验的 300114→302132 日期证据保存在 configs/research-code-event-evidence.json，未自动写入既有训练快照；两个代码的原始行情仍需按生效日期对照衔接，避免双计或截断。证券导出已识别 302 号段的创业板代码。[公司公告中的创业板规则依据](https://static.cninfo.com.cn/finalpage/2026-04-29/1225250614.PDF)

## 真实工程样本

样本在训练前列明：600036、000001、600053、600070、000004、300059、688001、002594，覆盖两市场、四类板块、历史 ST、停牌和退市情形。它是按覆盖案例选取的小样本，存在选择偏差，不能替代原定全 A 股证券池。

共有 20,087 条日线，来源 ST 标记 1,126 条、停牌标记 416 条。日线的来源 ST 标记作为 source_is_st 保存；没有伪造历史公告时刻，所以可交易风险状态仍是 unknown。ST 来源标记、代码和名称不进入 25 个模型特征。停牌时源量额为空，只在明确停牌状态下转为零量额，并保留原始空值及停牌字段；沿用价格不得当作可执行端点。

训练快照为 p1-real-pilot-snapshot-20260907-v1。最近报告在 p1-real-pilot-training-20260907-v2：训练 2018–2022 年、验证 2023 年、测试 2024 年一季度；两周期各单种子 17、单 epoch，保持正式的小型 Transformer 结构并运行序列展平 LightGBM 对照。未触及末年保留集，也未生成组合收益。

较早 v1 使用 2021 年前训练窗口，分区中没有真实 ST 标记。后续为覆盖 ST 场景调整工程分区，旧实验、原始参数和结果均保留，不按指标挑选窗口或模型结论。

实际训练/验证/测试的来源 ST 标记数：5 日为 158/271/58，20 日为 143/256/58；20 日测试的 464 条评分中有 1 条终点不可用，保持缺失标签并披露。两个实验文件哈希、检查点与特征名单已复验。[实验验证记录](../artifacts/p1-real-pilot-training-20260907-v2/verification-status.json)
