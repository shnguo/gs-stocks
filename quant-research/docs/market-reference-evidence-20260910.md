# 按可复核结果验收异常

用户确认：异常只需有足够证据支持可信结果，不要求每项必须取得对应公告。该原则已加入开发计划和 Rust 核验路径。

本轮使用已经保存的原始行情和因子记录重放核验，新增通过 18 个价格连续性边界，待核由 238 个降至 220 个，原 2,788 个已核实边界无退回。新增中 14 个不再依赖公告身份匹配，4 个虽有公告候选条款，但价格连续性由行情与因子证据单独验证。累计价格边界闭合 2,806 / 3,026。

## 当前验收条件

- 原始响应、采集回执和哈希可核对；证券代码及事件日期一致。
- 未复权的前一观察日收盘价与保留的源价格一致，前后报价均为正常交易观察。
- 新浪对应日期的因子增量计算出的参考价格，在分币精度上与 BaoStock 当日原始参考价一致。
- BaoStock 因子增量与该参考价的关系在原有相对容差 0.00001 内一致；未扩大容差。
- 不将两个供应方自动视为上游完全独立，保留供应方和原件来源说明。

以上证明仅限价格连续性。实际股东现金、送转股数或配股权益仍按自身证据核验，证据可以是可信的分配记录或其他可复核资料，也可以是公告；不会由因子反推出现金并作为真值。新增价格证明不自动解除股东收益标签屏障。

9 项相关 Rust 回归测试通过，Clippy 与差异检查通过。独立 Python 核验逐一读取 18 项的原始因子响应、行情记录及哈希，采用 Decimal 重算；所有旧源字段及 31 项因子修正保持一致，没有已通过边界退回。

新审计位于 artifacts/market-reference-evidence-20260910-v1/audit-v1。正在运行的模型仍使用原冻结数据集，因此其训练结果可与此前结果直接比较。新审计尚未物化为下一版训练候选，也未替换当前训练数据。

没有重新采集全市场数据，也没有部署 Worker。新的源代码与核验记录按既有流程归档到 R2，完成状态以该目录内的云端回执和恢复比对报告为准。
