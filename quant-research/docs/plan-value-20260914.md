# 固定买卖计划收益模型：第一轮结果

2026-09-14。第二步实验和独立复核完成；模型仍不具备正式建议资格。

## 设计

冻结 plan-value-v1：六个不同于滚动价格实验的开发季度；每窗 96 个训练日期、8 个选择日期、12 个独立校准日期、8 个评价日期。评价合计 48 个五日标签不重叠信号日期。仍为历史开发研究，最终封存区间未读取标签。

12 个固定买卖计划分别学习成交概率、结果可判断概率、成交且结果明确无歧义条件下的净收益、亏损概率和下行损失。训练、校准与选择均不将未知结果赋零；已知未成交订单的订单收益为零，成交条件收益为缺失。价格路径歧义单独保留，并在选定计划的保守情景中计入止损优先结果。

## 主要结果

所有下表比较均为独立校准后的学习模型相对同样校准的历史经验基线，日期等权、窗口等权。收益相关目标以已成交且结果明确无歧义样本为条件，不能解释成全部成交或整个账户的预期收益。

| 目标 | 相对基线误差改善 | 更优窗口 | 区块区间是否跨零 |
|---|---:|---:|---|
| 成交概率 Brier | 4.67% | 5/6 | 否 |
| 结果可判断概率 Brier | 1.15% | 6/6 | 否 |
| 条件净收益 MSE | 0.08% | 5/6 | 是 |
| 条件亏损概率 Brier | -0.20% | 2/6 | 是 |
| 条件下行损失 MSE | 1.36% | 5/6 | 是 |

模型主要学到了成交与结果可判断性；条件净收益 MSE 改善不足 0.1%，不确定性区间跨零，亏损概率没有改善。这还不能支持模型已学会挑选有稳定正向净收益的交易。

统一校准也没有稳定改善所有输出：学习模型条件净收益的 MSE 从未校准约 0.001378 上升到校准后约 0.001439，亏损概率 Brier 从约 0.242445 升至约 0.250912。两个版本均保留，不能事后只展示较好版本。下一轮要检验市场状态信息与校准跨时期偏移，而不是默认校准必然改善。

研究选择规则选出了 146,975 个股票日期计划，其中 1,539 个订单收益未知、654 个路径有歧义。已知收益仅为逐计划情景，包含已知未成交零收益，不能作为未来预期收益或组合收益。不同模型选定的股票/日期及成交覆盖不同，不能直接比较其单一已知均值宣称盈利增益。

双倍成本后，学习策略六个窗口中五个窗口的已知选定计划平均情景收益为负。该诊断不补齐未知结果，也未模拟账户现金、整手和组合容量；足以否定将本轮直接作为成熟交易策略发布。

## 验证与后续

核验 800 个登记哈希；以独立逐计划模拟复核 1728 个情景；重载保存模型复现 2160 个预测值；重算全部 240 个学习模型日期/目标 MSE，并对全部学习模型校准输出与选定计划索引作核对。该验证覆盖方法和产物，不等于真实成交或完整历史时点数据验收。

第一、二步试验均已完成且保留负面结果。下一步继续市场特征逐组对照，已实现 12 项信号日市场宽度/相对表现计算，并通过未来数据扰动与行顺序检查。它们基于当时可用股票输入群体，不能冒充官方指数。历史行业字段全部未知，行业接入仍待完成。

之后仍需推进 Transformer 的充分早停训练与 Kronos 同口径路径评估。本轮没有完成整个优化目标，未替换今天的日策略模型包，未做自动交易。
