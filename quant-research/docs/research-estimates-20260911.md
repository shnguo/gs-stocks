# 220 个遗留价格边界的研究处理

用户允许存在部分不严谨的数据。本轮将 220 个遗留边界全部纳入明确标注的近似研究版本，不再要求逐项找到公告才能继续特征研究。220 个均有处理结果，研究未处理数为 0；严格证明状态仍保留，未把近似处理改写成事实核验通过。

## 实际处理结果

| 方法 | 数量 | 研究默认权重 |
| --- | ---: | ---: |
| 跨供应方同日因子增量差异不超过 0.5%，保留原因子 | 136 | 0.75 |
| 公告中的交易所参考价公式支持保留因子 | 4 | 0.90 |
| 单条分配记录计算与保留因子差异不超过 0.5% | 20 | 0.50 |
| 证据不足，保留已有供应商因子 | 41 | 0.25 |
| 存在证据冲突，暂保留来源因子 | 18 | 0.10 |
| 根据已有分配记录估算缺失因子 | 1 | 0.25 |
| 合计 | 220 | — |

这些权重用于后续敏感性对照，不是统计置信概率，目前只写入逐事件台账，未改变正在运行的训练权重。不同供应商也不保证上游完全独立。证据冲突与低支持事件可以参与近似研究，但不能据此宣称原始数值已经证实。

唯一新增因子估算为 600710 在 2017-06-09 的分配边界：以此前价格 9.36 元、来源分配记录每股现金 0.054 元及送股比例 0，计算连续性增量 9.36 / (9.36 - 0.054)。估算累计作用于 2,247 条后续候选记录，单独标注估算来源，没有反推或虚构每位股东实际收到的现金。

另外，两份新浪响应因声明数量与实际条数不一致被排除，并记录原件哈希及拒绝原因；其余合格证据继续参与核验。未借此放宽原始响应完整性检查。

## 数据版本与使用边界

新版本目录为 artifacts/research-estimates-20260911-v1：candidate-v1 保存完整 717 个 Parquet，canonical-v1 保存可重建的规范研究导出，research-estimates.jsonl 在两者中记录全部处理方法和原始异常。原严格事件清单和 220 条严格价格屏障继续保存。研究价格序列解除这批边界切断，但不同证券身份不会因此合并。

共 11,463,243 条候选记录的 21 个来源字段逐列保持一致；现有已核实因子修正保留，仅新增上述一个估算事件。全 A 股范围以及 ST、未知状态保持原样。股东权益标签继续独立处理，不因价格连续性放宽而自动生成分红收益。

正在运行的全市场训练继续使用原冻结快照。本轮生成的近似版本用于后续单独对照，不能与旧训练结果混为同一数据版本。标准严格导出入口会拒绝近似候选，必须显式使用携带不确定性台账的研究导出入口。

重建规范导出时，在已恢复的 Rust 工程中运行 research-export-estimated-training，并依次传入 candidate-v1、catalog/manifest.json、quality、一个新的输出目录。归档包内保存这三个输入目录和原始数据版本回执；导出产生新的路径与时间戳，数据表可按记录的哈希核验。

## 核验和持久保存

独立 Python 按 Decimal 重新计算全部 220 个处理增量，核对所有使用的新浪原件哈希，并逐列验证 717 个 Parquet。Rust 单元回归、Clippy 和差异检查通过；严格导出拒绝近似候选的实际命令验证通过。

云端恢复验收已完成：326 个 Rust 源码文件和 198 个增量包文件均已存入 R2，下载到新目录后独立逐文件核验一致。使用此前已经从云端恢复的父候选、严格审计，加上本轮云端恢复的增量包，实际重建全部 729 个候选文件，与本轮原件逐字节一致。

源码回执为 code-receipt.json，数据增量回执为 delta-receipt.json，独立报告为 code-restore-verification.json、delta-restore-verification.json、rebuild-verification.json。增量包压缩后 707,534 字节；行情父数据继续由既有云端归档保存。早先 83 分块的全量重复上传因网络失败较慢，在增量恢复通过后停止，已有检查点保留，它不作为成功归档凭据。规范 CSV 可从重建候选及原有 catalog/quality 导出，无需重新采集行情。

新规范导出包含 5,901 条历史证券候选、11,459,092 条有效价格、34,944 个已核实分配事件，仍保留 2,578 个股东权益标签屏障。全部导出价格、来源状态及股东标签已与原冻结版本逐列比对；仅候选价格序列和明确记录的因子估算不同。35 项 Rust 主程序回归及 2 项表层重写测试通过，Clippy 与差异检查通过。

逐项清单见 ../artifacts/research-estimates-20260911-v1/event-handling.csv。本轮没有提交或推送代码，没有部署 Worker。
