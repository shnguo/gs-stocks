## 手动运行与截止时间

既有入口 scripts/run_daily_token.sh 会记录交易日历、行情采集、校验、模型输入、各随机种子的训练和推理、排名、发布以及成熟复盘的耗时。记录位于每日存储目录的 operations，独立于不可变模型运行目录。

在首个预测交易日上海时间 09:15 前实际发布的榜单才具备前瞻资格。新运行如果启动时已过截止时间，默认返回 missed_publication_deadline，停止启动新训练；明确提供 --signal-date 可以生成标为迟发的历史研究报告。及时启动也不能保证及时完成，最终资格按真实发布时间判断。完成过的运行仍可复用，且不会重复施加梯度更新。

当前工作只使用手动入口，没有启用定时任务，也没有运行新的模型训练。

新增正式成交证据导入、逐股票缺口和离线发布时间预检，契约与命令见 execution-evidence-v1.md。候选及匹配记录在发布后立即冻结，先于成熟复盘；已有冻结队列不因复盘代码更新而重建。

## 独立复盘和研究台摘要

在 quant-research 目录运行以下命令即可复盘已有报告，不训练或推理：

    PYTHONPATH=src:scripts .venv/bin/python scripts/review_daily_research.py \
      --store artifacts/daily-token-live-v2 \
      --output ../stock-indicator-dashboard/public/research/latest.json

默认从 current.json 读取最新行情来源。可用 --source 指定另一个包含 snapshot 的结果数据目录。成交模拟需要正式快照契约；增量训练快照保留未知值，只提供诊断，不能授权成交模拟。

可重复提供 --event-overlay 指定已经冻结的事件覆盖层目录。程序验证完整控制组与原始模型的股票和收益对应关系，再接入事件窗口榜和确认榜。不存在事件产物时，页面显示未发布。

每日入口提供 --research-review-config、--research-export 和 --event-overlay 参数，复盘协议默认读取 configs/research-review-v1.json。不会修改已完成运行的模型配置。

public/research 作为本地生成产物被 Git 忽略。/research 使用同源摘要文件，显示行情截止日期和摘要生成时间。发布网站时必须单独提供这份导出数据；缺失文件会显示明确的空状态。该文件包含公开证券研究摘要，不包含 API 凭证、私密路径或个人账户持仓。

## 紧凑证据与重放

每个信号日在 decisions 中保存独立、不可变的记录，包含：

- 完整股票级候选队列及原始排名、参考收益、模型分歧和阶段特征；
- 原始输入版本中截至信号日的 60 日价格历史；
- 已有的每日行情预测分位数；
- 当时的股票元数据、风险状态、规则和公司行动表；
- 各榜单真实发布时间、输入文件哈希、模型配置、复盘协议和计算代码哈希；
- 在结果成熟前构建的同板块匹配对照。

decision-publications 保存当前记录指针。即使大型模型路径和原始运行目录后来移除，独立复盘仍可从这些紧凑记录继续追加成熟结果。不能补造未保存的预测或发布前特征。

每次新结果在 research-reviews 下使用结果快照、决策记录、协议及计算代码哈希创建新目录；既有记录不会覆盖。research-latest.json 是可更新的摘要指针。

既有 --r2-retain 流程分别归档大型核心输入与紧凑复盘证据。重复复盘不因新的耗时记录重新归档整套大型模型产物；归档 ID 包含核心代码版本或紧凑内容身份。沿用原有 R2 完整恢复校验。本轮没有调用云端归档或部署。

## 两种收益的含义

参考价情景保留报告原来选定的退出日期，比较模型参考收益与实际日线低价/高价情景，报告高估、绝对误差、方向概率误差及排名相关性。股票级未知结果继续为未知。板块、行业及波动率分组使用发布时可见资料；波动率分组以完整模型股票池为基准。

成交模拟只针对及时发布且窗口成熟、资料完整的榜单，使用首个预测日开盘买入、第五个预测日收盘退出。复用既有现金账本，保留风险状态、涨跌停、交易单位、结算、公司行动、费用、滑点、流动性及行业约束。信号股票池只读取真实发布时已知的风险修订，开盘成交另检查执行时的风险状态。无法退出的持仓保留在终值中。

固定评估前 20 名，不以低排名补充缺失结果或无法成交的候选。报告 1、2、3 倍成本情景的净值收益、最大回撤、候选成交覆盖和未退出持仓。模拟成交不是券商实际成交。

训练快照、未验证的历史信息、缺失风险状态、规则或公司行动、未知涨跌停价、缺少完整结果窗口和迟发报告均显示明确阻碍项，不生成成交收益。

## 新信息与模型诊断

上涨初期和事件榜的匹配在结果读取前冻结，在同板块控制原模型排名、历史波动率及流动性。结果成熟后分别追加固定开盘/收盘情景差和不利波动差；这些配对仍属于观察性影子比较，不代表因果估计或实际成交。

匹配记录自身也必须在首个预测交易日 09:15 前冻结，才会积累前瞻匹配样本。对历史及时日报补建的匹配记录属于回溯研究，不会因此获得前瞻资格。合成市场不计入真实成熟日期或匹配进度。

摘要分别积累有效前瞻日期和已知配对，显示既有 50 个日期、1,000 个配对门槛。参考收益诊断和分组矩阵为收益校准、下行风险及排序目标的下一轮比较提供输入。当前证据不足，不自动训练辅助头、重设事件权重或提升候选模型。

experiments 保存模型配置、榜单协议及复盘协议的不可变登记，避免把多轮历史尝试误认为一项未调整过的实验。
