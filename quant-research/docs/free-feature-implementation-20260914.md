# 免费日度信息特征接入与增量实验

2026-09-14：完成东方财富历史日度信息接入、冻结新浪档案辅助核对，以及三个既有开发窗口的 LightGBM 增量实验。数据链通过验收；新增特征尚未证明改善条件收益预测，模型不晋级每日策略基线。暂不需要购买 Tushare 来继续开发。

## 数据接入

Rust 主采集器读取东方财富 RPT_VALUEANALYSIS_DET，按指定交易日分页，保留原始响应、请求、时间、哈希、失败及重试证据；网络失败最多三次重试。必须验证页数/总行数、跨页唯一性、日期、证券身份、有限数值和价格乘股本等于市值。独立回放从原始响应重新建立标准化记录，拒绝被修改的证据、半成品、跨日期返回和封存日期。

已完成 371 个目标日期、1,745,942 条来源记录，范围来自原先冻结的三个窗口。每个日期同时通过 Rust 回放和独立 Python 重算。数据位于 artifacts/free-features-source-20260914-v1，逐日分区及证据索引支持恢复；完成后的重复调用只校验并返回，不改变来源身份。失败目录不会被覆盖。

主流程的换手率为既有快照原始成交量（股）÷同日流通股本（股）×100。上一轮 1,052 条换手率与东方财富日线交叉测试已通过，因此这条接入链使用可直连的估值端点，不依赖此前需要代理的 K 线端点。没有修改系统代理或安装 AKShare。

新浪作为辅助核对，使用上轮冻结的 20 只股票原始历史档案。此次 6,215 条重叠收盘价与主源完全相同；6 条主源记录在新浪没有对应成交日，保留未匹配状态。未实现自动向新浪切换或覆盖东方财富数据，也不把股本事件日期伪造成成交日。辅助报告位于 artifacts/free-feature-source-audit-20260914-v1。

## 特征与隔离

保留原有 27 项特征，新增 11 项：换手率、总/流通市值对数、总/流通股本对数、流通股本占比、盈利收益率 E/P、账面净资产/价格 B/P、销售额/价格 S/P、经营现金流/价格 CF/P，以及来源可用标记。保留负估值；分母为零或字段缺失时标记为 NaN，不用零值假装有数据。

只按同一证券和同一信号日期精确连接；该日收盘价与原快照相差超过 0.01 元时，整组新增值标缺失。原始样本顺序、价格、标签、未知成交/终值和原买卖规则不变。训练日期为信号收盘日，计划针对下一交易日开始的 T 至 T+4。所有开发输入及标签都早于 2025-08-07；来源接口并没有提供或证明原始披露时间。

三个窗口各分区共 1,730,158 条输入，其中 47,817 条来源缺失，未删除；价格不匹配为 0。各分区完整来源覆盖约 95.09%—99.64%。本次预设分区覆盖门槛为 90%，全部通过。

特别限制：当前来源对退市证券的历史缺失，可能让缺失模式带入“后来退市”的信息；财务历史值也可能经过后续修订。即使连接日期正确，也不能据此认证无未来信息。本轮结果仅用于开发诊断，不能作为实际可获收益或严格历史回测证明。去掉可用标记也不会自动消除其他字段的缺失模式，需要另外取得可验证的历史版本。

## 实验与结果

固定窗口为原 plan-value 实验的 fold 1、7、15，分别评估 2021-12 至 2022-01、2023-06 至 07、2025-06 至 07，共 24 个评估日期。每个窗口沿用 96/8/12/8 个训练/选参/校准/评估日期、60 次迭代上限、原随机种子和模型参数。只增加一个信息特征实验组，无调参搜索。本轮使用 LightGBM 做低成本信息筛选，没有替换或删除 Transformer/Kronos 路径。

相对同窗口、同校准状态的原 27 特征模型，误差相对下降百分比如下；正数为改善，负数为变差。

| 指标 | 原始模型 | 校准后模型 |
| --- | ---: | ---: |
| 成交概率 Brier | +0.5810% | +1.0507% |
| 成交后结果可确定概率 Brier | +0.0603% | +0.0247% |
| 条件净收益 MSE | +0.0016% | +0.0394% |
| 条件亏损概率 Brier | −0.0464% | −0.1227% |
| 条件下行损失 MSE | −0.1153% | +0.4884% |

预先声明的主要比较是原始模型的条件净收益 MSE，改善只有约 0.0016%，3 个窗口中 2 个改善，日期区块自助法 95% 区间跨零。校准后的收益 MSE 区间同样跨零。成交概率改善不能等同于交易收益改善。

校准后模型选单的双倍成本、已知结果情景均值，三个窗口分别约 −0.7661%、−0.0232%、−0.0020%。这些是按评估日取平均的已知单计划情景结果，不是组合收益；未解决结果继续单列。原始和校准后结果均保存，未挑选有利版本作宣传。

结论：免费来源足以支持这轮信息实验；新增信息对成交概率有帮助，但未显示稳定的收益预测收益，不能升级每日策略。后续应围绕条件收益/下行风险的目标与校准、缺失机制和原始披露时点做针对性检查，再决定是否扩大模型或引入更多财务字段。

## 可复用入口

- Rust：research-capture-daily-features DATE NEW-OUTPUT-DIR；research-replay-daily-features CAPTURE-DIR。该入口明确限定封存日前的历史研究日期，不能直接用作今天的生产增量入口。
- scripts/free_feature_ingest.py：--prior、--rust-repo、--output，固定本轮三个窗口，可恢复未完成采集，已完成目录保持身份。
- scripts/free_feature_ablation.py：freeze / run / fit；冻结来源与父实验后，运行同队列对照。
- scripts/verify_free_feature_ablation.py：--output 实验目录，独立复核。
- scripts/audit_free_feature_sources.py：--source、--probe、--output，新浪辅助核对。

实验产物：artifacts/free-feature-ablation-20260914-v1。汇总与覆盖：artifacts/free-feature-results-20260914-v1/summary.json。运行命令必须使用项目 .venv 中的 Python；实验拟合和验证使用冻结代码副本，详情见 experiment.json 与 frozen-manifest.json。
